# ÉLORA E-Commerce - Backend API

This directory is reserved for future backend development (Node.js/Express, REST API endpoints, Database models, Authentication, and Payment Gateway integration).

In accordance with Phase 1 specifications, the backend is kept strictly decoupled while the frontend operates with a rich mock data store, simulated API delays, and localStorage state persistence.

## Planned Architecture
- **Runtime:** Node.js / Express or Fastify
- **Database:** PostgreSQL or MongoDB with Prisma/Mongoose
- **Auth:** JWT authentication with refresh tokens / OAuth 2.0
- **Payments:** PayFast, JazzCash, EasyPaisa, Stripe integration
- **Media:** Cloudinary / AWS S3 image storage
